# 🎓 Student Grade Calculator

## 📌 Project Description
Student Grade Calculator is a simple Python-based project that calculates students' grades based on their marks.

The program accepts the student's name and marks, validates the input, calculates the grade, and displays an encouraging message according to the marks obtained.

## 🎯 Objectives
- To calculate student grades automatically.
- To understand Python conditional statements.
- To implement input validation.
- To practice functions and while loops.
- To display encouraging messages to students.

## 🛠️ Technologies Used
- Python 3
- Visual Studio Code (VS Code)

## ✨ Features
- Accepts student name and marks.
- Validates marks between 0 and 100.
- Handles invalid inputs such as alphabets.
- Uses if-elif-else statements for grading.
- Uses functions to organize the code.
- Uses a while loop for input validation.
- Displays encouraging messages for each grade.

## 📊 Grading System

| Marks Range | Grade | Message |
|---|---|---|
| 90–100 | A | Excellent work! Keep shining! |
| 80–89 | B | Very Good! Keep it up! |
| 70–79 | C | Good job! Keep improving! |
| 60–69 | D | Nice effort! Work harder! |
| 0–59 | F | Don't give up! Keep practicing! |

## ⚙️ How to Run the Project

1. Install Python 3 on your computer.
2. Open Visual Studio Code.
3. Open the Student Grade Calculator project folder.
4. Open `student_grade_calculator.py`.
5. Run the program using the Run button or terminal.
6. Enter the student's name.
7. Enter marks between 0 and 100.
8. View the calculated grade and encouraging message.
