

# Personal Introduction Program

## Project Overview
A simple Python program that asks the user for
their name, age, hobby, and city, and displays
a friendly personalized welcome message.

## Technologies Used
- Python 3
- Visual Studio Code

## Features
- Accepts user input
- Stores information in variables
- Uses f-strings
- Displays a personalized introduction
- Shows friendly welcome messages

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python personal_intro.py

5. Enter your information.

## Code Structure
- personal_intro.py - Main Python program
- README.md - Project documentation
- requirements.txt - Dependency information
- screenshot.png - Program output screenshot

## Algorithm
1. Start the program.
2. Display the welcome message.
3. Ask for name, age, hobby, and city.
4. Store the answers in variables.
5. Display the personalized introduction.
6. End the program.

## Testing
Test the program with different names,
ages, hobbies, and cities.

Expected result:
The program displays the entered information
correctly in the welcome message.
