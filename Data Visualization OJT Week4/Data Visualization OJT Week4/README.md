# E-commerce Sales Data Analysis Project

## 1. Project Overview

The E-commerce Sales Data Analysis project uses Python to analyze sales data and generate meaningful insights through data analysis and visualization.

The project uses Pandas for data cleaning and analysis and Matplotlib for creating professional charts and graphs.

## 2. Objectives

- Load sales data from a CSV file.
- Explore and understand the dataset.
- Identify and handle missing values.
- Remove duplicate records.
- Clean and validate the dataset.
- Calculate important sales metrics.
- Create different types of charts.
- Identify sales trends and patterns.
- Generate a complete analysis report.

## 3. Technologies Used

- Python
- Pandas
- Matplotlib
- Visual Studio Code
- CSV Dataset

## 5. Installation

First, install Python on your system.

Install the required libraries using:

```bash
py -m pip install -r requirements.txt
```

## 6. How to Run the Project

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Make sure the dataset is available in the data folder.
4. Install the required libraries.
5. Run the Python program.

Command:

```bash
py sales_analysis.py
```

## 7. Data Analysis Process

### Step 1: Data Loading
Load the sales dataset using Pandas.

### Step 2: Data Cleaning
- Check missing values.
- Remove duplicate records.
- Convert columns into correct data types.
- Validate sales data.

### Step 3: Data Analysis
Calculate:
- Total Revenue
- Total Quantity Sold
- Average Sales
- Highest Transaction
- Lowest Transaction
- Best Selling Product
- Best Performing Region

### Step 4: Data Visualization

Create three different charts using Matplotlib.

**Bar Chart:** Displays product-wise sales comparison.

**Line Chart:** Shows monthly sales trends.

**Pie Chart:** Displays region-wise sales distribution.

### Step 5: Report Generation
Generate a report containing numerical results, charts, and important findings.
